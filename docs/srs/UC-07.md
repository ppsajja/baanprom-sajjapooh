# UC-07 จองงานบริการซ่อมบำรุง (fully dressed)

ระบบ: บ้านพร้อม R1 | ผู้เขียน: กลุ่ม X | เวอร์ชัน: 1.0 (เข้า Baseline B1) | ที่มา: EV-004, EV-009, EV-012, EV-023

| หัวข้อ | รายละเอียด |
|---|---|
| Primary actor | ลูกค้าที่ลงทะเบียนแล้ว |
| Secondary actors | ช่าง, เจ้าหน้าที่ call center (จองแทนลูกค้า A2), Payment Gateway (IF-01), ระบบส่งข้อความ (IF-02) |
| Goal | ลูกค้าได้ช่างที่ว่างจริงในช่วงเวลาที่ต้องการ โดยวางมัดจำแล้วได้งานสถานะ "ยืนยันแล้ว" |
| Precondition | ลูกค้าเข้าสู่ระบบแล้ว (UC-10) และมีที่อยู่ให้บริการอย่างน้อย 1 แห่ง (UC-02) |
| Postcondition (สำเร็จ) | มีงาน 1 รายการสถานะ "ยืนยันแล้ว" ช่วงเวลาของช่างเป็น "จองแล้ว" มีรายการชำระมัดจำ 1 รายการ ลูกค้าและช่างได้รับแจ้ง |
| Postcondition (ล้มเหลว) | ไม่มีงานค้างสถานะ "รอชำระเงิน" เกิน 30 นาที ไม่มีการตัดเงิน ช่วงเวลากลับเป็น "ว่าง" |
| Trigger | ลูกค้ากด "จองช่าง" |

## Main success scenario

1. ลูกค้าเลือกประเภทงานซ่อม และที่อยู่ให้บริการ
2. ระบบแสดงช่างที่ว่างภายใน 7 วันข้างหน้า เฉพาะช่างที่มีทักษะตรงประเภทงาน และอยู่ในระยะให้บริการ (BR-03)
3. ลูกค้าเลือกช่างและช่วงเวลา ระบบล็อกช่วงเวลานั้นไว้ชั่วคราว
4. ระบบแสดงราคาประเมิน ยอดมัดจำ และเงื่อนไขการยกเลิก (BR-01)
5. ลูกค้ากดยืนยัน และชำระมัดจำผ่าน Payment Gateway (IF-01)
6. ระบบสร้างงานสถานะ "ยืนยันแล้ว" และแจ้งลูกค้าและช่างภายใน 60 วินาที (IF-02)

## Alternative flows

- A1 (ขั้น 2) ไม่มีช่างว่างใน 7 วัน: ระบบเสนอช่วงเวลาถัดไปที่มีช่างว่าง หรือให้ลูกค้าเข้า waitlist (UC-08) แล้วจบ use case
- A2 (ขั้น 1) เจ้าหน้าที่ call center จองแทนลูกค้า: เจ้าหน้าที่เลือกลูกค้าจากคอนโซลก่อน แล้วทำขั้น 1 ถึง 6 แทนลูกค้า การชำระมัดจำส่งลิงก์ให้ลูกค้ากดเอง

## Exception flows

- E1 (ขั้น 5) ชำระมัดจำไม่สำเร็จ หรือไม่ชำระภายใน 30 นาที: ระบบยกเลิกงานอัตโนมัติ ไม่มีการตัดเงิน ช่วงเวลากลับเป็น "ว่าง" แจ้งลูกค้า
- E2 (ขั้น 5) ช่วงเวลาถูกลูกค้าอื่นจองไปก่อนที่การยืนยันจะเสร็จ: ระบบไม่ตัดเงิน แจ้งว่าช่วงเวลาถูกจองแล้ว และกลับไปขั้น 2 โดยคงประเภทงานและที่อยู่ที่เลือกไว้ พร้อมเสนอช่วงเวลาใกล้เคียง
- E3 (ขั้น 6) ช่างปฏิเสธงานหลังยืนยัน: งานเปลี่ยนเป็น "กำลังหาช่างใหม่" ระบบจับคู่ช่างใหม่ (UC-05) ถ้าหาไม่ได้ คืนมัดจำเต็มจำนวน (BR-01 R4)

## Business rules ที่อ้าง

BR-01 นโยบายคืนมัดจำ | BR-02 ช่างรับงานซ้อนเวลาไม่ได้ | BR-03 ระยะให้บริการสูงสุด
